Revisar imagens dos artigos

Para cada artigo já vem marcada uma sugestão (borda verde). Clique em outra pintura para trocar, em Manter a atual para não mexer, ou em Sem imagem para usar o painel na cor da seção. Se encontrar no Commons uma pintura melhor, cole o link da página do arquivo no campo do artigo. Suas escolhas ficam salvas neste navegador. No fim, clique em Baixar escolhas.json e mova o arquivo para a pasta seo/imagens do site.
